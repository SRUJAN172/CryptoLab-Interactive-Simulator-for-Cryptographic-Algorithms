# CryptoLab - Interactive Simulator for Cryptographic Algorithms

## 📋 Overview

CryptoLab is an interactive web-based simulator designed to help users understand and visualize cryptographic algorithms. Built with JavaScript, HTML, and CSS, this educational tool provides hands-on experience with various encryption, decryption, and hashing techniques.

**Language Composition:**
- JavaScript: 53.4%
- HTML: 33.2%
- CSS: 13.4%

## 🎯 Features

- **Interactive Algorithm Visualization** - Step-by-step visualization of cryptographic processes
- **Real-time Encoding/Decoding** - Instantly encode and decode messages using various algorithms
- **Educational Focus** - Clear explanations and demonstrations for learning cryptography
- **User-Friendly Interface** - Intuitive design making complex algorithms easy to understand
- **Multiple Algorithm Support** - Covers various cryptographic techniques
- **Input/Output Display** - Clear visualization of transformation results

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No additional dependencies required

### Installation

1. Clone the repository:
```bash
git clone https://github.com/SRUJAN172/CryptoLab-Interactive-Simulator-for-Cryptographic-Algorithms.git
cd CryptoLab-Interactive-Simulator-for-Cryptographic-Algorithms
```

2. Open the application:
```bash
# Simply open index.html in your web browser
open index.html
# or use a local server
python -m http.server 8000
# Then navigate to http://localhost:8000
```

## 📚 Supported Algorithms

This simulator includes interactive implementations of:
- Caesar Cipher
- Substitution Cipher
- ROT13
- Base64 Encoding
- Hash Functions (MD5, SHA-1, SHA-256)
- And more cryptographic techniques

## 💡 Usage

1. **Select an Algorithm** - Choose from the available cryptographic algorithms
2. **Enter Your Input** - Input the text or data you want to process
3. **Configure Parameters** - Set any necessary parameters (e.g., shift values, keys)
4. **Visualize Process** - Watch the step-by-step transformation
5. **View Results** - See the encrypted/decrypted output
