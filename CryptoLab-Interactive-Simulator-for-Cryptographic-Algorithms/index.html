Classical Cipher

Caesar Cipher

Each letter is shifted by a fixed number of positions in the alphabet.

How it works

The Caesar Cipher replaces every letter with another letter that appears a certain number of steps later in the alphabet. A shift of 3 turns A into D, B into E, and so on.

Term tip Plaintext becomes ciphertext by applying a fixed shift key.

Playfair Cipher

This algorithm encrypts letters in pairs using a 5×5 matrix built from a keyword.

How it works

Playfair combines letters into digraphs, then uses their positions in a keyword-based matrix to transform them. For education, I and J share one matrix cell.

Hill Cipher

Hill Cipher uses linear algebra, converting letters into numbers and multiplying them by a key matrix.

How it works

For a 2×2 Hill Cipher, letters are grouped in pairs, converted to numbers, multiplied by the key matrix, and reduced modulo 26 to create ciphertext.

Block Cipher

DES Algorithm

DES is a Feistel network that repeatedly applies permutations, expansion, XOR, substitution, and swapping across rounds.

How it works

DES takes a 64-bit block and processes it through an initial permutation, sixteen Feistel rounds, and a final permutation. This educational simulator keeps the flow clear and visual.

RSA Algorithm Simulator

RSA builds a public and private key pair from prime numbers, then uses modular arithmetic for encryption and decryption.

How it works

Choose two prime numbers, compute n and φ(n), select a public exponent e, then calculate the private exponent d. The message is encrypted with the public key and decrypted with the private key.

Key Exchange

Diffie-Hellman Key Exchange

Alice and Bob can agree on a shared secret over a public channel without sending the secret itself.

How it works

Both parties agree on a public prime and base. They keep their secret exponents private, exchange computed public values, and independently derive the same shared secret.

Cryptographic Hashing

SHA-256 Hash Generator

SHA-256 turns input data into a fixed-length 256-bit hash. Even tiny input changes create dramatically different outputs.

How it works

A hash function is one-way: it produces a digest but is not meant to be reversed. SHA-256 is widely used for integrity checking and digital signatures.
